# Ready-to-use prompts

[← Home](../README.md) · [Catalog](../catalog/README.md) · [Agent skills](../skills/README.md)

Portable prompts to help discover **free IT courses with official achievements**, not just certificates.

| Prompt | Purpose |
| --- | --- |
| [Verify course + official outcomes](verify-course.md) | Check certificates, digital badges, diplomas, awards, records and official bonuses with issuer evidence. |
| [Проверка курса и наград](verify-course.ru.md) | Полная русская версия промпта проверки. |
| [Learning path](learning-path.md) | Plan a route toward skills and officially documented achievements. |

These are text templates — no proprietary model or account is required to read or adapt them. Fresh verification needs a browsing-capable assistant and an independent check of the sources.

See the [Course Verifier skill](../skills/course-verifier/SKILL.md) for a structured reusable workflow.
