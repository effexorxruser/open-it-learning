# Copy-ready prompts

[← Home](../README.md) · [Course catalog](../catalog/README.md) · [Agent skills](../skills/README.md)

These prompts work best with an assistant that can browse **current official sources**. They don't require the maintainer's research lab or a particular model. If no browsing tool is available, the assistant must report that sources could not be independently checked.

| Prompt | Purpose |
| --- | --- |
| [Verify an IT course and certificate](verify-course.md) | Confirm whether a free course qualifies for the verified catalog. |
| [Build a credential-aware learning path](learning-path.md) | Recommend a sequence of official courses with disclosed credential conditions. |
| [Проверка курса на русском](verify-course.ru.md) | Русскоязычная версия первого промпта. |

Paste the prompt, fill in the variables, then review its evidence. **Generated output is always a candidate until verified.**

For automated use, see the [Course Verifier skill](../skills/course-verifier/SKILL.md).
