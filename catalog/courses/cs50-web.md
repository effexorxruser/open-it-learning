### Free CS50 Certificate — CS50’s Web Programming with Python and JavaScript

**Тип:** сертификат об окончании · **Стоимость получения:** бесплатно

Earn at least 70% on each required project, including the final project, following academic honesty rules. Register with edX and enable/link the CS50 Gradebook; request the free certificate from the Gradebook after completion using GitHub sign-in. The FAQ currently sets the course deadline to 30 June 2027; request/download the certificate before that deadline. This proposal covers the free CS50 certificate, not paid edX verification, professional credentials or academic credit.
