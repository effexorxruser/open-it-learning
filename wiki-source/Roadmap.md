# План развития

[[← Главная|Home]] · [[Как участвовать|Contributing]]

Wiki отражает планы **публичной библиотеки курсов**, а не внутренней агентной лаборатории.

## Этап 1 · Надёжный фундамент

- [x] Создать публичный репозиторий и README на нескольких языках.
- [x] Определить категории официальных достижений и бонусов.
- [x] Опубликовать первую версию правил проверки и модель данных.
- [x] Подготовить промпты и переносимый скилл Course Verifier.
- [ ] Независимо проверить и опубликовать первый подходящий курс.
- [ ] Утвердить лицензии для кода и контента.

## Этап 2 · Удобный каталог

- [ ] Собирать курсы по направлениям: сети, информационная безопасность, программирование, облака и данные.
- [ ] Разделить награды по типам: бейджи, сертификаты, дипломы, грамоты, ваучеры и другие.
- [ ] Учитывать языки, уровни, сроки, бесплатность и дополнительные расходы.
- [ ] Отслеживать устаревшие ссылки и изменения условий выдачи.

## Этап 3 · Готовые маршруты и инструменты

- [ ] Сформировать образовательные маршруты по навыкам и ролям.
- [ ] Расширить библиотеку промптов и агентных скиллов.
- [ ] Сделать машиночитаемый экспорт проверенных записей.

## Этап 4 · Дополнительные интерфейсы

- [ ] Изучить возможность создания read-only MCP поверх опубликованного каталога.
- [ ] Оценить отдельный сайт или удобный интерфейс поиска.
- [ ] Описать политику обновлений, исправлений и вклада сообщества.

Выполненным считается только то, что реально опубликовано и доступно для использования.
