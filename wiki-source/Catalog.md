## Назначение

Open IT Learning собирает **бесплатные IT-курсы**, за которые можно получить определённый и официально подтверждённый результат: сертификат, цифровой бейдж, диплом, грамоту, награду, документ о прохождении или бонус, непосредственно связанный с курсом.

[Открыть каталог в репозитории](https://github.com/effexorxruser/open-it-learning/tree/main/catalog)

## Текущий статус

Бесплатное обучение и сертификат платформы после пяти проектов, экзамена и проверки результата. Другие предложенные курсы остаются на проверке.

## Что будет в карточке курса

| Поле | Зачем |
| :--- | :--- |
| Название и организатор | Точно определить программу |
| Официальный URL | Открыть исходную страницу без посредников |
| Область IT и уровень | Сориентироваться по теме и сложности |
| Продолжительность, языки | Оценить практическую доступность |
| Бесплатность обучения | Отличить бесплатный курс от пробной версии |
| **Официальные результаты** | Перечислить каждую награду отдельно по типу |
| Условия получения | Требования к прохождению, тестам, регистрации |
| Дополнительная стоимость | Отдельно от бесплатности самого курса |
| Доказательства и дата проверки | Возможность перепроверить утверждения |

Если курс даёт бейдж и платный сертификат, это **две разные позиции** в перечне результатов. Бейдж не переименовывается в сертификат.

## Порядок публикации

1. Кто-то предлагает кандидат и официальные ссылки.
2. Проверяется бесплатность обучающих материалов.
3. Проверяются конкретная награда и её условия.
4. К каждому существенному утверждению прикрепляется официальный источник.
5. Проводится проверка **смысла**, а не просто совпадения цитат.
6. Только после этого запись допускается в [verified](https://github.com/effexorxruser/open-it-learning/tree/main/catalog/verified).

Неподтверждённые курсы можно обсуждать в Issues и исследовательских заметках, но **не в проверенном индексе**.

## Есть подходящий курс?

[Предложить курс через GitHub Issues](https://github.com/effexorxruser/open-it-learning/issues/new/choose). Добавьте страницу программы и официальное подтверждение награды, а также требования для её получения.
